# 뉴스 브리핑 규칙

핵심: **요약은 직접 쓰고, 근거는 링크로.**

## 날짜

- 오늘 날짜는 KST로 계산한다: `TZ=Asia/Seoul date +%F`
- 루틴 컨테이너는 UTC라서 06:45 KST에 그냥 `date`를 쓰면 전날 날짜가 나온다.

## 수집 규칙

- 기준 시점: 실행 시각 기준 지난 24시간 기사
- 분야는 `config/briefing.json`의 `sections`를 따른다. 분야별 기사 수도 거기에 맞춘다 (분야당 5개, 전체 25개 안팎. 톱기사는 종합 5개에 포함)
- 같은 사건은 하나로 합치고 출처를 여러 개 단다
- 한 기사당 출처 최소 1개, 가능하면 2개 언론사로 교차 확인
- 확인되지 않은 속보, 루머성 기사, 단독 주장만 있는 기사는 제외
- 출처 URL은 실제로 열어 본 기사 주소만 쓴다. 검색 결과 목록 주소, 언론사 메인, 추측한 주소는 금지

## 브리핑 데이터 (`briefings/YYYY-MM-DD.json`)

```json
{
  "date": "2026-11-08",
  "generated_at": "2026-11-08T06:55:00+09:00",
  "headline_summary": ["주요 소식 한 줄 1", "주요 소식 한 줄 2", "주요 소식 한 줄 3"],
  "top_story": {
    "title": "직접 쓴 제목",
    "summary": "직접 쓴 요약 3~5문장",
    "section": "종합",
    "sources": [{"name": "언론사명", "url": "https://..."}]
  },
  "sections": [
    {
      "name": "경제",
      "items": [
        {"title": "...", "summary": "2~3문장", "sources": [{"name": "...", "url": "https://..."}]}
      ]
    }
  ]
}
```

- `headline_summary`는 정확히 3줄, 한 줄 40자 안팎
- `top_story.section`과 `sections[].name`은 config의 분야 이름과 같아야 한다
- 톱기사는 `sections` 안에 다시 넣지 않는다
- 제목은 원문 제목을 복사하지 않고 25자 안팎으로 직접 쓴다
- 요약은 쉬운 말로, 한 문장 50자 안팎. 가족 누구나 읽기 편하게

## 검수 기준 (editor가 확인)

1. 모든 출처 URL이 실제로 열리고, 요약 내용이 그 기사에 있다
2. 기사 문장 또는 원문 제목을 그대로 옮긴 곳이 없다 (연속 15자 이상 일치 금지)
3. 같은 사건이 두 번 나오지 않는다
4. 날짜가 KST 오늘 날짜와 같다
